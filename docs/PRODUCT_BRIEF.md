# Product brief — WeatherNow

## Purpose

A responsive dashboard for searching a place and viewing current conditions plus a five-day forecast from Open-Meteo.

## Main workflow

Search for a location, review current conditions and forecast dates, and use the last location as a convenience only.

## Scope

The current page is a prototype. Roadmap items and sample records in this repository are documentation, not claims that those features already exist. A successful session lets a user complete the core task and understand whether the information is local or externally sourced.
